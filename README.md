## What I found

- Discoveries spiked around 2014-2016 (Kepler mission data)
- Transit method tends to find planets with shorter orbital periods; 
  Radial Velocity tends to find higher-mass planets
- Confirmed with a t-test (p = 0.0103) that this difference is 
  statistically significant, not just random variation
